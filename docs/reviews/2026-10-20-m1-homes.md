# M1 addendum — multiple homes and shared homes — 2026-10-20

Live acceptance showed the account owns no usable home: it only belongs to shared homes
(as administrator) and to several of them. `/home/device_list` is account-scoped and does
not return shared-home devices, so the list looked empty.

## Change

- `GetHomesAsync` calls `POST /app/v2/homeroom/gethome` with
  `{"limit":300,"fetch_share":true,"fetch_share_dev":true,"fetch_cariot":true,"plat_form":0,"app_ver":9,"fg":true}`
  and reads `result.homelist` (owned) plus `result.share_home_list` (shared). Array placement
  decides `IsShared`; `shareflag` is ignored. Room membership comes from `roomlist[].dids`.
- `GetDevicesAsync(session, home)` calls `POST /app/v2/home/home_device_list` with
  `home_id`, `home_owner` (the owner's uid, not the signed-in uid), `limit:300`,
  `get_split_device`, `support_smart_home`, `get_cariot_device`, `get_third_device`, and pages
  on `has_more` / `max_did`. Room names are joined client-side.
- The desktop header gained a home switcher with a 共享 tag. The first home that actually has
  devices is selected; refresh keeps the current home; changing homes cancels the in-flight
  load and clears stale rows.

## Review

| # | Sev | Finding | Resolution |
| --- | --- | --- | --- |
| 1 | P2 | A broken page cursor (empty, repeating or looping) returned a partial list as success. | Throws `MiHomeException` with the protocol error code, naming the cursor. |
| 2 | P3 | Missing regressions for shared-only lists, leading-zero ids, room precedence. | Added three tests. |
| 3 | — | `gethome` paging beyond the first page is not implemented. | Documented in code as deliberate; accounts with more than 300 homes would be truncated. |

Desktop review of the switcher reported no important issues.

## Live evidence

`gethome` for the real account returned one owned home (no devices) and three shared homes;
one of them, 东里, has 13 devices across 7 rooms. `home_device_list` returned all 13 devices
with `isOnline`, and the app switched from the owned home to 东里 and rendered them.

# M4 shell redesign, packaging and diagnostics — 2026-10-21

## Shell (concept C, phase 1)

- Borderless window with a custom title bar: home switcher, page title, settings. Mica backdrop.
  Caption buttons remain the system ones.
- Sidebar: 主页, one entry per room, 活动, 设置. Collapses to an icon rail below 1200 logical
  pixels; below 700 it becomes a top strip with a horizontally scrolling room chip row, so every
  room stays one tap away.
- 主页: 信息仪表 (values derived from sensor-like devices), 场景 (current home, confirmation on
  run), 快捷开关 (grouped by `DeviceClass`, inline power switch per device), 收藏 (placeholder).
- 房间: virtualized tile wall; each tile shows monogram, name, room, online state and an inline
  power switch; the rest of the tile opens the detail sheet.
- 设备详情: docked sheet at ≥1200, overlay below that; keeps the virtualized property list, the
  per-property apply, the action confirmations and the "已写入，当前值未确认" behaviour.
- 活动 and 设置 are real pages; settings carries the working sign-out. Account, members,
  consumables, notifications, appearance/light effects and about are listed as 未实现 rows.

## Fixes from review

| # | Sev | Finding | Resolution |
| --- | --- | --- | --- |
| 1 | P1 | Power was inferred from `siid 2 / piid 1`, which can write the wrong capability. | Power is the first writable bool whose type ends `:property:on` (or `:property:power`) in the resolved spec; no IID fallback; disabled when absent. |
| 2 | P2 | Refresh cancelled device operations and lost unconfirmed values. | Rows merge by `Did`; the list lifetime is separate from operation lifetimes; in-flight work survives a refresh. |
| 3 | P2 | Closing the sheet with an idle draft left the tile disabled. | Idle drafts are discarded on close (value restored, pending cleared); `IsWriteUnconfirmed` is untouched. |
| 4 | P2 | Compact tiles hid the room, so same-named devices were indistinguishable. | Room shown on compact rows and in the toggle's automation name. |
| 5 | P2 | Inline power still asked for confirmation. | Inline power writes immediately; actions and scenes still confirm. |
| 6 | P2 | Rows removed by a refresh could still submit new writes from the open sheet. | `IsRemoved` gates new writes and is re-checked after the action dialog; a quiet notice is shown. |

## Packaging and diagnostics

- `winapp package ... --generate-cert` produces a signed MSIX; `docs/build.md` documents the
  runtime prerequisites, certificate trust and install steps.
- Crash log stores no exception messages: type names, source, version and frames reconstructed
  from `StackTrace(exception)` only. Written with `CreateNew`, pruned to 20 files.

## Verified live

- 1280×840 logical window renders; home shows 信息仪表, 场景 rows for the selected home and
  快捷开关 grouped under 灯 with working toggles.
- At ~550 logical pixels the sidebar collapses and rooms appear as chips.
- Settings shows the account id, the 未实现 rows and the sign-out button.

## Known limits

- 收藏, 活动 and most settings sections are placeholders.
- Device panels are still the generic spec list; remote-style panels (AC, switch banks, light
  effects) are phase 2.
- M3 LAN remains unverified on real hardware.
- `gethome` paging beyond 300 homes is not implemented.
